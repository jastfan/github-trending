### 1. Claude Code
```bash
claude mcp add gittrends -- npx -y gittrends-mcp
```

### 2. Cursor IDE (`.cursor/mcp.json`)
```json
{
  "mcpServers": {
    "gittrends": {
      "command": "npx",
      "args": ["-y", "gittrends-mcp"]

}
```
