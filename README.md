### 1. Claude Code
```bash
claude mcp add gittrends -- npx -y gittrends-mcp
```

```json
{
  "mcpServers": {
    "gittrends": {
      "command": "npx",
      "args": ["-y", "gittrends-mcp"]
    }
  }
}
```

### 3. Antigravity IDE (`mcp_config.json`)
```json
{
  "mcpServers": {

  }

```
